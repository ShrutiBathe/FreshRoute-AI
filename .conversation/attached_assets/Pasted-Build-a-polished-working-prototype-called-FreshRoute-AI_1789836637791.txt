Build a polished working prototype called:

FreshRoute AI
Real-Time Accessibility Intelligence & Dynamic Routing

This is an international hackathon prototype. The goal is NOT to build a production-scale system. Build a convincing, functional MVP that clearly demonstrates the project's core innovation:

Detect → Verify → Decay → Update → Reroute

==================================================
1. PRODUCT CONCEPT
==================================================

FreshRoute AI is an AI-powered accessibility intelligence and navigation platform.

The system detects accessibility features and temporary obstacles from images/video and user reports, maps them geographically, assigns confidence and freshness scores, detects changes over time, and dynamically recommends accessibility-aware routes.

The key difference from a static accessibility map is:

"Is this path accessible RIGHT NOW, how reliable is that information, and what is the best accessible alternative?"

The prototype must demonstrate this concept visually and interactively.

11. ROUTING LOGIC
==================================================

Do not simply calculate the shortest path.

Create a scoring function using:

distance
accessibility score
obstacle severity
confidence
freshness

Example conceptual scoring:

route_score =
accessibility_weight * accessibility_score
+
confidence_weight * confidence
-
distance_weight * normalized_distance
-
obstacle_penalty

Allow different weights depending on user preference.

For wheelchair users:

Accessibility weight should be high.

For general users:

Distance weight can be higher.

Make the routing algorithm modular so it can later be replaced with OSRM/GraphHopper or another routing engine.
